Stickers.

chef.png is the sticker drawn on a block that has been picked out in the
repository: the thumbs-up drawing of Andrew. Drop the file in here at that
exact name and it appears on every picked row.

Until the file is here, a picked row draws the word PICK in a badge instead,
because a missing image renders as a broken-image icon and that is worse than
no sticker at all.

Anything in this folder is served from the root of the site, so public/chef.png
is /chef.png in the page.
