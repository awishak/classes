# Seed library

Small stories, examples, and hooks that are fun to talk about. Each seed is tagged by the **concept** it teaches and the **class** it serves, so you can pull the right one when building a lecture.

## How to add a seed

Copy the template block below. **Concept** and **Class** are the two fields that matter most. Slot type tells you where it fits in a [sequence](sequences.md). Source is so you can recall or cite it later.

Slot vocabulary: `opener` `problem` `solution` `visualization` `call-to-action` `example` (see [README](README.md)).

```
### <short memorable title>
- **Concept:** <tag, e.g. triangulation>
- **Class:** <Comm 118 / Comm 2 / Comm 4 / any>
- **Slot:** <opener / problem / visualization / ...>
- **Source:** <where it came from>

<the hook itself, in a sentence or two. End with the turn: what concept it lands.>
```
